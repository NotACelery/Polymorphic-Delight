# Changelog

## 1.0.0

- Added Polymorph recipe selection to Farmer's Delight Cooking Pots and Cutting Boards.
- Added recipe selection for placed Skillets, Campfires and Soul Campfires.
- Added individual and bulk selection for Farmer's Delight-style Stoves.
- Added independent recipe selection for each active Campfire and Stove slot.
- Preserved cooking progress when changing the selected recipe.
- Persisted active selections through saves and world reloads.
- Added compatibility with both Polymorph and Polymorph+.
- Added automatic support for compatible Farmer's Delight Stove subclasses.
