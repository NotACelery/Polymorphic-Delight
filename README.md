# Polymorphic Delight

Fabric integration between Farmer's Delight Refabricated and Polymorph+ for Minecraft 26.3.

## Requirements

- Minecraft 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API
- Farmer's Delight Refabricated 3.6.30
- Polymorph+ 1.5.0
- Java 25

## Features

- Recipe selection for the Cooking Pot, Cutting Board, Skillet, Stove, and Campfire
- In-world recipe indicators for compatible Farmer's Delight blocks
- Per-slot and shared Stove selections

## Building

Run `build.bat`. The build script downloads the required development dependencies and copies the release JAR to `dist/`.
