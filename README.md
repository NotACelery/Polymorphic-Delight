# Polymorphic Delight

Fabric integration between Farmer's Delight Refabricated and Polymorph+ for Minecraft 26.1.x.

## Requirements

- Minecraft 26.1, 26.1.1, or 26.1.2
- Fabric Loader 0.19.5 or newer
- Fabric API
- Farmer's Delight Refabricated 3.6.30
- Polymorph+ 1.5.0
- Java 25

## Features

- Recipe selection for the Cooking Pot, Cutting Board, Skillet, Stove, and Campfire
- In-world recipe indicators for compatible Farmer's Delight blocks
- Per-slot and shared Stove selections

## Building

Place the required Farmer's Delight Refabricated, Polymorph+, and Cardinal Components JARs in `libs/`, then run `build.bat`. The release JAR is copied to `dist/`.
